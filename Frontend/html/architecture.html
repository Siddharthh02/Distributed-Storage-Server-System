🖥Amazon EC2
Compute Nodes
Multiple EC2 instances act as storage nodes, each handling file upload and retrieval requests routed by the load balancer.
💾Amazon EFS
Shared Storage
Elastic File System is mounted across all EC2 instances, enabling concurrent read/write access from any node to the same data.
🛡AWS Elastic LB
Traffic Distribution
Application Load Balancer distributes incoming client requests across available EC2 nodes, preventing bottlenecks on a single server.
📄Amazon RDS
Metadata Management
MySQL database stores file metadata — name, path, size, upload timestamp, and the serving EC2 node for each stored file.
📊AWS CloudWatch
Observability
Tracks CPU usage, network I/O, disk utilization and memory across all EC2 nodes. Triggers alarms on threshold breaches.
🔐IAM + Security Groups
Access Control
IAM roles and VPC security groups enforce least-privilege access, ensuring only authorized services interact with the infrastructure.
